# Store facts and limits

Platform behaviour the listing depends on. Read at step 1 and re-check at step 6 (character counts). Store rules change: confirm current limits in App Store Connect / Google Play Console help (or by web search) before the member uploads — if you can't check, say the limits below are unverified.

## Store facts — last reviewed October 2026 (re-verify with web search before quoting)

| Fact | Detail | Source |
| --- | --- | --- |
| Apple title | ≤30 characters | App Store Connect documentation |
| Apple subtitle | ≤30 characters | App Store Connect documentation |
| Apple keyword field | ≤100 characters, not user-visible; comma-separated, no spaces after commas | App Store Connect documentation |
| Google Play title | ≤30 characters | Google Play Console help |
| Google Play short description | ≤80 characters | Google Play Console help |
| Google Play long description | ≤4,000 characters | Google Play Console help |
| App preview video | ≤30 seconds; auto-plays silently in search and on the product page | App Store Connect documentation |
| Description indexing | Apple does **not** index the long description for keyword ranking (pure conversion copy); Google Play **fully indexes** it (conversion + natural keyword density; stuffing is penalized) | BONUS App Store Listing doc → Principles; Apple / Google docs |
| Caption OCR | Apple OCRs screenshot caption text and uses it for keyword indexing — captions are ASO fields | BONUS App Store Listing doc → Tactics (as of the last review) |
| Conversion as ranking signal | Listing-view → install conversion is a primary ranking signal in both stores; Google Play also weights retention | BONUS App Store Listing doc → Numbers That Set the Stakes |
| Caption legibility | Legible on the smallest current iPhone display (5.4-inch at the last review): minimum 36pt at full size, bold, high contrast, sans-serif | BONUS App Store Listing doc → Tactics |
| Review prompt APIs | `SKStoreReviewController` (iOS); Google Play In-App Review API (Android) | Apple / Google developer docs |
| Native A/B testing | Apple Product Page Optimization; Google Play Store Listing Experiments | Apple / Google docs |
