# EVALS.md template

The exact shape of `docs/EVALS.md`. Fill every bracket. Scenarios are grouped by job; for a chat assistant, **Request** becomes a numbered script of user turns; for a skill or plugin, keep the Triggering table. Input files live in `docs/evals/<scenario-id>/`.
