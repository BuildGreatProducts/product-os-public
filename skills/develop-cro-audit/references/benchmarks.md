### Performance & Core Web Vitals
- LCP good <2.5s, poor >4s; INP good <200ms, poor >500ms; CLS good <0.1, poor >0.25 — Google Core Web Vitals
- Every 100ms of LCP delay ≈ 1.11% conversion drop — Deloitte/eBay study
- Sites passing all three CWV thresholds see ~24% fewer abandons — source not recorded
- 53% of mobile users abandon if load >3s — source not recorded

- Removing a stock-image hero entirely beats keeping it by +4% — source not recorded
