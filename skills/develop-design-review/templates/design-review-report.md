# Design review report template

The skeleton for `docs/design-reviews/YYYY-MM-DD-HHMM-design-review.md`. Fill every bracket with real values from the review; the examples (`#2563EB`, `body-xs`, `#D14638`…) show the level of specificity, not content to copy. Bullets stay tight — the whole report reads in 5–8 minutes.

## Contents

- Header and Summary
- Inconsistencies (P0 → P3), ending with the paste-ready fix prompt
- New Patterns (Promote / Refactor / Defer)
- Already-aligned
- Promotion checklist and Fix checklist
- Sources

## Template
